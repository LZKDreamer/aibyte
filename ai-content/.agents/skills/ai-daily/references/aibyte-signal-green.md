# AIBYTE 信号绿：公众号日报主题

这是一套原创的 AI 日报主题。设计目标是让读者先被头条抓住，再快速扫完热榜；它只借鉴绿色杂志风的层级方法，不复制其他主题的组件或代码。

## 设计 token

| 用途 | 值 |
| --- | --- |
| 信号绿 | `#0B8A65` |
| 薄荷底 | `#EAF8F2` |
| 高光沙金 | `#F3C969` |
| 标题墨色 | `#15231E` |
| 正文灰绿 | `#3C4B45` |
| 线条 | `#DCE8E1` |
| 页面底 | `#FCFDFB` |

字体使用系统中文无衬线；正文 `14px / 1.85`，字距约 `0.35px`，内容区左右留白 `20px`。整篇只让绿色承担导航、序号和关键数据，让沙金只点亮头条中的一个短语。

## 组件顺序

1. **封面卡**：`AIBYTE · AI HOTLIST`、日期、两行以内的内标题、首条截图；外部标题卖“为什么点开”，封面标题只讲“里面最重要的是什么”。
2. **热榜索引条**：只写“24 小时 / 综合热度 / AI”，不放长目录。
3. **独立动态卡**：大号序号、热度小胶囊、短标题、2–4 段文字。卡片之间用细线和留白，而不是每条都用大色块。
4. **资料尾注**：低对比度，单独收尾。

## 公众号兼容

- 只用内联样式和基础 `section/p/span/strong/img` 标签；不用 `style`、`script`、class、grid 或绝对定位。
- 需要装饰点、细线时放入带 `leaf=""` 的内部 span，防止微信清理空元素。
- 同一段落只使用一个字号；需要不同字号时拆成多个段落。
- 每段最多一种醒目强调。卡片可以有边框或浅底，但同一条不要同时堆阴影、渐变、粗边和多种高亮。
