# 日报发布检查

## 榜单与选题

- 采集页面是赛道榜，当前筛选状态为 `24小时 / 综合热度 / AI`。
- 第一条是榜单第一名；全篇包含 8–12 条，保持原始热度顺序。
- 官网和 X 原帖只补充细节，不改变榜单选题与顺序。

## 可读性

- 标题点出第一条的具体变化，并写明当天有多少条值得看。
- 开头短，不强行提炼“共同趋势”。
- 每条均为独立短新闻，正文没有机械的三段式标签。

## 封面和素材

- 第一条有人工看过、确实相关的封面：关联图片、视频缩略图或榜单卡片截图。
- `materials.json` 记录实际素材，且仅将其用作 illustration。

## 交付

- `article.md`、`wechat.html`、`sources.json`、`materials.json` 完整。
- Markdown 与 HTML 的标题、条目数和排序一致。
- HTML 为内联样式；正文不显示 X 原始链接。
